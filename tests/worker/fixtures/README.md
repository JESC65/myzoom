# Fixtures de la API de RealtimeKit

Respuestas simuladas con la forma documentada en los tipos oficiales del paquete npm `cloudflare` 7.3.0
(`resources/realtime-kit/meetings.d.ts` y `presets.d.ts`), porque `developers.cloudflare.com` no era accesible
desde la sesión que las escribió (ver docs/DECISIONES.md D-001). Los valores son sintéticos.
